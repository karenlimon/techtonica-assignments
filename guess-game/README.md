Guess My Number

A browser game built with HTML and JavaScript. The game picks a secret random number, and you keep guessing until you get it right. After each guess, it tells you whether the answer is higher, lower, or correct.

## Features

- Secret random number generated each round
- Higher / lower / correct feedback after every guess
- Wrong guess counter
- List of numbers you've already guessed
- Choose the range of the secret number (Easy, Medium, Hard)
- Game timer that shows how long you took to win

## How to Play

1. Pick a difficulty level.
2. Type a number into the input box and click **Guess**.
3. Read the hint (higher, lower, or correct) and guess again.
4. Keep going until you find the secret number.

## How to Run

No installation or build step is needed.

1. Clone this repository:
   ```
   git clone [your repository URL]
   ```
2. Open the project folder:
   ```
   cd [your project folder name]
   ```
3. Open `index.html` in your web browser (double-click the file, or right-click and choose **Open with** your browser).
